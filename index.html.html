[!] ТРЕБУЕТСЯ НАСТРОЙКА FIREBASE — ОДНОРАЗОВО

Открой HTML-файл в редакторе и выполни 6 шагов:

1. Иди на console.firebase.google.com → Создай проект
2. Authentication → Sign-in method → включи Email/Password
3. Firestore Database → Create → Start in test mode
4. Project Settings → Your apps → Web (⊕) → скопируй firebaseConfig
5. Вставь данные в скрипт вместо ТВОЙ_API_KEY и остальных
6. Замени ТВОЙ_EMAIL@gmail.com на свой — получишь права владельца
Firestore Rules (вставь в Rules tab):
rules_version = '2';
service cloud.firestore {
 match /databases/{db}/documents {
  match /{doc=**} { allow read, write: if request.auth != null; }
}}
